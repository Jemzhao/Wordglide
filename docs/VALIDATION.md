## 0.2.5 失败译文恢复与翻译超时

- 快捷替换及浮窗替换获得译文后，如果提交失败或结果不确定，主窗口显示最近一次恢复记录，支持查看原文/译文、复制译文、在浮窗查看及关闭。不自动打开主窗口或抢走目标输入框焦点；快捷反馈提示可以打开 Wordglide 查看/复制。
- 恢复记录只在内存保存原文、译文、目标语言与说明，不保留 AX 目标、光标或可重放的粘贴能力；仅保留最近一次未完成操作，关闭或退出后清除。没有增加持久历史记录或后台剪贴板读取。
- 本机翻译的语言可用性检查与翻译共用30秒期限。一次性完成门禁在超时或调用取消时立即恢复调用方，取消系统 session，不等待忽略取消的底层操作；底层迟到的响应不能写缓存。语言包下载准备流程保持原样，不使用这个期限。
- 浮窗加载状态增加取消，超时及可重试错误增加手动重试。快捷替换超时在主窗口保留原文与原目标语言，手动重新翻译后显示结果并更新恢复卡，提供复制；所有重试均不复用旧 AX 目标、不自动粘贴。
- 修正复核发现的恢复记录竞态：重试等待期间关闭或更新恢复卡后，旧成功或超时回调都不能复活或覆盖记录；旧的粘贴确认也不能覆盖新操作的恢复内容。已经发出的单次粘贴继续做结果确认和剪贴板清理。
- `scripts/test.sh` 的 **112项 XCTest** 与无权限自检全部通过，其中新增18项恢复测试和10项超时测试。使用隔离剪贴板验证精确复制、原剪贴板在无译文/关闭时不变；受控等待器验证取消、超时、晚结果、同实例重试、缓存及原错误保持，不调用真实引擎或模拟用户按键。
- 重新导出并检查20张原生视图，包含新增恢复卡、超时卡、超时浮窗、加载取消的深浅色版本；原12张主窗口、设置、展开原文、中英方向和替换底栏布局保持完整。

## 0.2.4 输入法、富文本和多屏边界

- 用户在本轮前已明确反馈 Codex 输入框兼容正常；这是用户实测结果。工具仍不读取 Codex 界面，不将其作为本轮自动化验收结论。
- 输入法检查增加公开的 `AXTextInputMarkedTextMarkerRange`，兼容原有组词标记；有效的标记范围即使折叠也视为组词中。抓取、等待和提交前重复检查。部分编辑器或输入法不提供组词状态，不能据此保证覆盖所有输入法。
- 直接替换与浮窗替换共用可失效的一次性提交门禁。等待期间的真实外部输入、焦点/原文/选区变化和屏幕布局变化会使旧请求失效；在全选前、进入粘贴前复核。程序自身粘贴事件不触发误取消；已经发出的单次粘贴继续做结果确认和剪贴板清理，不因取消而重复发送。
- 支持可选的 `AXSelectedTextRanges` 检查，拒绝多个选区、多个光标及错误/不一致的范围；未实现该属性的编辑器继续使用原来的单选区检查。仅当待替换文字含 U+FFFC 附件占位符时拒绝，不因未选中区域有附件而禁止普通局部替换。
- 两项原生 NSTextView 富文本测试使用隔离剪贴板、独立 UndoManager 和无窗口视图：覆盖局部及整框纯文本粘贴，emoji、组合字符的 UTF-16 边界，未选中区域的字体、颜色与链接，以及一次撤销恢复完整原文和全部属性、重做恢复粘贴结果。译文不逐词映射被替换范围内的混合样式；真实编辑器如何解释粘贴和撤销仍由该编辑器决定。
- 多屏逻辑以屏幕几何快照选择触发屏幕，保留主屏坐标原点；覆盖上方/左侧负坐标、屏幕间隙、菜单栏边缘、移除显示器和小数缩放坐标。浮窗内容与面板共享可见区域预算，拖到窄屏/矮屏后重新排版并保留操作区；显示器变化取消旧坐标取词并重排浮窗/反馈。小于最低支持视口（344 × 284 pt）时明确提示，避免显示裁掉操作区的卡片。
- `scripts/test.sh` 的 **84 项 XCTest** 与无权限自检全部通过，包含 10 项屏幕几何/布局测试、6 项组词证据测试、6 项提交门禁测试、7 项内容策略测试和3项模拟等待期间输入的替换边界测试。另一次只读审查未发现可证实的回归。
- 最终 0.2.4 release 构建、Info.plist、严格签名验证及6轮原生窗口检查通过。重新导出12张深浅色原生视图并检查展开原文及中英方向浮窗；签名 designated requirement 与 0.2.3 完全一致，没有修改隐私权限或签名身份。重启新版后通过设置页实测辅助功能、屏幕录制均显示“已授权”，语言包就绪，原快捷键和目标语言设置保留；已返回翻译工作区。
- 本轮用 TextEdit 创建了带粗体、斜体和 emoji 的样例，确认可读取富文本。Computer Use 的应用定向按键未触发 Carbon 全局快捷键，鼠标操作后工具连接中断，因此没有完成真实跨进程替换/撤销验收；上述富文本结论来自原生隔离测试。未验证实际拼音/第三方输入法组词，也未连接多台物理显示器，仍需实机覆盖。
- 保留一次普通粘贴与既有截止确认机制；响应特别慢的编辑器仍可能得到“结果不确定”提示，程序不会自动补发。未延长剪贴板临时占用或引入重试。

- 48项XCTest与无权限自检通过。新增自动方向和立即加载、手动目标与原文取消旧结果的检查；单击替换以自身进程无效目标验证会进入事务但不会改动剪贴板。假翻译器不依赖语言包，过期结果测试使用受控完成顺序。

## 跨应用人工验收清单

在当前构建授权并主动准备语言包后，使用**示例文本**逐项核对。可以在浏览器打开 [选区样例](../scripts/selection-fixture.html)，并在 TextEdit 等原生应用中重复同样流程。

| 场景 | 操作与预期 |
| --- | --- |
| 首次准备 | 依次点击语言包与权限按钮；取消下载或拒绝权限后仍可打开应用和试用原文，不应自动反复弹窗 |
| 真实翻译 | 试用中输入英语译中文、输入中文译英文；无网络且模型已装时可翻译 |
| AX 悬停 | 在 TextEdit/浏览器英文稳定停留，只有图标；移入图标才展开；单词和句子模式分别核对 |
| OCR 屏幕取词 | 同时授权辅助功能/屏幕录制，在图片英文当前行及单词试用；空白处不应出现邻行结果 |
| 路径与关闭 | 从文字移到图标再移到浮窗，不应因间隙消失；进入后移开按延迟关闭；固定后保留 |
| 选区持久性 | 鼠标选区与 ⌃⌥T 均可打开；移开原文后仍能点语言、复制、固定和关闭；外部输入/点击可关闭未固定浮窗 |
| 自动语言 | 选中中文自动译英文，选中英文自动译简体中文；手动切换目标语言后，旧译文不能覆盖新结果 |
| 浮窗替换 | 选中示例句子中间部分 → 查看译文 → 点击“替换”；前后未选中内容完全不变，处理中不能重复提交 |
| 重新验证 | 查看译文后改变原文、选区或前台应用，再提交应拒绝；不能重选旧范围，也不能自动粘贴到新应用 |
| 撤销 | 成功后在目标应用按 ⌘Z；核对原编辑器是否恢复整段原文、富文本和选区 |
| 用户剪贴板 | 提交期间在其他应用复制新示例文字；等待后剪贴板应仍为新内容 |
| 不确定结果 | 使用不报告完整值/响应缓慢的编辑器时，提示检查原文且无第二次粘贴；主窗口保留结果及可复制的译文 |
| 失败恢复 | 已生成译文但替换失败时，主窗口可查看/复制本次译文；关闭恢复卡或退出后清除，无自动补发粘贴 |
| 超时与取消 | 受控测试验证 30 秒超时、主动取消及迟到结果失效；手动重试只翻译供查看，不复用旧输入框目标 |
| 密码/保护区域 | 仅用 fixture 的示例密码；不应识别、弹出替换操作或 OCR 内容。真实应用的保护标记不同，需逐应用验证 |
| 只读与不透明控件 | 只读文本不显示替换；无法确认编辑能力或完整原文时只提供翻译与复制 |
| 多显示器 | 在主屏上、下、左侧显示器分别试用；核对取词命中、OCR 区域、图标与浮窗不越界 |
| 暂停和关闭窗口 | 暂停后无自动取词；关闭主窗口后菜单栏仍可打开设置、主动翻译和退出 |
